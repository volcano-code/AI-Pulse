# 研究证据链：Unicode 与无证据边界

## 本批复现

1. `İ` 或 `ß` 经 casefold 会扩张。旧检索在折叠文本中得到位置，却用作原文偏移。`'İ' * 100 + 'agent'` 会返回 start=130、end=105、空 quote；旧 inspect/final 仅比较 Python 切片，反向空切片恰好匹配而误通过。
2. 内部自动把“智能体”扩展为 agent 等词。合法 400 字问题因此超过内部检索参数上限，无证据返回被误标 model_or_evidence_error，而不是正常不足证据。

## 修复与可证明范围

- 最早折叠命中位置映射回原文 Unicode 字符索引后再截取窗口，不改动保存快照。
- inspect 与最终保存独立检查：offset 必须是整数（bool 不算），`0 <= start < end <= len(text)`，引用非空且等于原文切片。负数、越界、反向、空引用不能作为已验证证据；最终门槛失效时清空生成 claims 并标记需处理。
- 自动扩展仅追加放得下的完整词，不截断原始问题；无空间则不扩展。工具预算仍生效，正常短问题仍可从中文扩展找到英文 evidence。
- 回归包含真实检索的 Unicode 扩张、中文/非 BMP、跳过 inspect 的最终门槛、脚本模型生成 claims 后的最终拒绝，以及400字/多扩展词/单工具预算的无证据降级。

这些检查只证明引用字符位置与快照相等，**不证明摘要语义受支持、来源可信或事实正确**。生成 claims 仍须人工审核。混合检索的语义相关性、真实模型质量、中文评测覆盖与检索阈值仍需独立评估；本批没有调用真实供应商、联网研究或付费服务。
