# v4 标签歧义：AI 辅助语义裁决建议

状态：**AI 辅助建议，未经过人类裁决，也不是独立人工审核或金标**。本文只解释三个既有案例；不修改冻结 fixture、原报告、协议或历史分数，不运行评测。下面的建议必须经过另行审核、版本化后，才可用于新的敏感性分析。不得用它们覆盖首次实验结果或声称提高了模型质量。

## 共同判断规则

1. 证据必须在问题允许的 scope 内，实体、对象、时间和数量含义一致。主题相似不构成回答支持。
2. **直接支持**：原文给出所问事实，允许明确的常规语言释义，例如“免费”表示文本所述开放使用不收费。
3. **有限组合支持**：允许同一对象的明确事实组合，以及可展示的简单算术；不允许猜测缺失条件、补造合同、预测未来或把分钟数当容量。
4. 区分“相关证据集合”与“最小充分证据集合”。相关集合中的全部文档并不都必须检索到才能回答；反之，单篇相关文档也未必足以回答完整问题。现有 `relevant_snapshot_ids` 只表达集合，无法表达替代证据或联合充分条件。
5. 下文“建议相关 ID”使用相关证据并集语义。最小充分集合另列，不能把两者混成同一个 Recall 分母解释。

## 1. n-dev-11：免费与每月价格

- 来源：`research_eval_development_v4.json`。
- 原问题：**镜湖方案多少钱每月**。
- 原标签：`relevant_snapshot_ids=[]`，no-answer，scope=current。
- 原文 `n-dev-lake` 全文：
  > 镜湖方案免费开放，支持人工审核。
- 精确支持段：**“镜湖方案免费开放”**。

### 建议

在“询问当前材料所描述的使用费用”的通常解释下，建议改为有答案，相关 ID 为 `['n-dev-lake']`；最小充分集合也是 `{'n-dev-lake'}`。

有界答案示例：“按这份材料，镜湖方案免费开放，未说明需要支付月费；材料没有提供独立的月付套餐或未来收费承诺。”

不宜无条件输出“月付套餐价格为0元/月”：原文没有币种、月付合同、权益、附加服务或有效期限。“免费”足以支持当前所述开放使用不收费，不足以支持未来一直免费。尤其不能据此回答另一个案例中的“2027年还免费吗”。

### 可证伪规则及歧义

- 如果题目明确询问收费附加套餐、月付合同价、特定权益或未来年份，当前支持不成立；应拒答或只说明材料缺失。
- 如果上下文证明“免费”仅限试用而问题问正式订阅，此标签建议应撤回。
- 当前题目未指定上述条件，因此建议采用有界可回答解释；若标注协议要求必须出现明确的“每月金额”，保留 no-answer 也有一致的理由，但应公开这种更严格规则，不能按实验收益逐题切换。

## 2. h4_retention：正式账号保留期限

- 来源：`research_eval_holdout_v4.json`。
- 原问题：**钴蓝正式账号保留日志多少天？**
- 原标签：`['h4_cobalt']`，有答案，scope=current。
- `h4_cobalt` 全文：
  > 钴蓝归档器保留日志三十天，每晚执行一次清理。归档内容采用只读存储。
- `h4_cobalt_trial` 全文：
  > 钴蓝试用账号只保留日志七天，不适用正式账号的三十天保留期。
- 精确支持段：`h4_cobalt_trial` 的 **“正式账号的三十天保留期”**。
- 补充相关段：`h4_cobalt` 的 **“钴蓝归档器保留日志三十天”**，该段没有独立标明账号类别。

### 建议

维持有答案；建议相关 ID 并集为 `['h4_cobalt', 'h4_cobalt_trial']`，纠正原集合漏掉最直接证据的问题。严格的最小充分集合为 `{'h4_cobalt_trial'}`。答案是正式账号三十天。

`h4_cobalt` 是相关的通用规则，可作佐证；但只凭其文字，不能忽略另有试用类别这一事实，自动把所有账号都解释为三十天。若后续协议采用“每篇必须独立直接支持”的窄相关性定义，则应只标 `h4_cobalt_trial`，而非以上并集。

### 可证伪规则及歧义

- 引用必须明确匹配“正式账号”；仅找到“三十天”但数字属于其他对象，不算直接支持。
- 若相关段在另一时段或不在允许 scope 内，不能沿用此判断。
- 目前两个快照均在当前范围且日期一致，无冲突。追加相关证据 ID 会改变 Recall 分母，其影响不能被当作检索系统本身变化。

## 3. h4_compare：保留期限比较

- 来源：`research_eval_holdout_v4.json`。
- 原问题：**钴蓝正式账号和试用账号的日志保留期相差多少天？**
- 原标签：`['h4_cobalt', 'h4_cobalt_trial']`，有答案，标记 multi_document。
- 两份原文同上。
- 精确充分支持段，完整位于 `h4_cobalt_trial`：
  > 钴蓝试用账号只保留日志七天，不适用正式账号的三十天保留期。

### 建议

维持有答案和相关 ID 并集 `['h4_cobalt', 'h4_cobalt_trial']`。但应撤回“必须两份文档才能回答”的解释：`{'h4_cobalt_trial'}` 已是最小充分集合，该句直接绑定试用七天与正式三十天，有限算术为 **30 − 7 = 23天**。`h4_cobalt` 提供冗余佐证，而非必需输入。

今后可另增“存在多份相关资料”与“回答必须跨文档组合”两个不同标记。当前冻结 multi_document 标签不改，但不能用此案例宣称已经测得必需的多文档推理能力。

### 可证伪规则及歧义

- 只有三十天或只有七天的证据不足以完成比较；缺少另一数量时不能自行补齐。
- 两个数量必须对应同一服务、同一有效时间、同一单位，并分别绑定正式和试用账号。
- 即使检索只命中 `h4_cobalt_trial`，基于原集合的 Recall 也只有1/2，但这不等于答案缺少一半语义依据。此差异体现指标表达能力的限制，不是调整旧分数的理由。
